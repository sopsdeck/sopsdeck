Source of truth

Your files, on disk

Projects are folders. Managed Files are dotenv, JSON, and YAML encrypted with SOPS. GitHub and CI are destinations, not a second vault.

Access

Public keys only

Teammates and CI receive Age public keys. Private keys never go in Git, chat, or a shared .env.keys file.

Git

Sync, never force

Commit ciphertext, then Sync: fetch, fast-forward only, push. Diverged branches stop. History stays encrypted until you open it.

Workspace

Folder-first, like a focused editor.

One sidebar of project folders, files as leaves, values masked until you reveal them. Encrypt & save writes only to the local file. The WebView never holds keys on disk.

From source · macOS first

Build the CLI, then the app.

Signed downloads come later. Until then, Sopsdeck is a Go binary the desktop app invokes as a sidecar. 

go test ./internal/cli/
go build -o sopsdeck ./cmd/sopsdeck

cd desktop && bun install
SOPSDECK_BIN="$PWD/../sopsdeck" bun run tauri -- dev
