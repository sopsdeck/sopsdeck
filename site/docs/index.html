What the product is, proved

Living pages generated from tests, the asset catalog, and CHANGELOG.md.

  • Living features — generated from test names. If a behavior is not named here, it is not specified by a test yet.
  • Public seams — where tests must live, and which delivery phases still have none.
  • Product assets — stills, clips, walkthrough, and CLI casts from ./scripts/demo.
  • Versioning — Epoch SemVer; CHANGELOG.md is canonical.
  • Domain language — words from CONTEXT.md.
  • Notes — generated from CHANGELOG.md.
