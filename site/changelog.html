Unreleased

  1. FeatureClipboard modal: on app focus, a sniffed secret, Age recipient, or absolute path opens a confirm modal — paste into the open Managed File, Grant Access, or open the folder as a Project.
  2. Feature`sopsdeck rename OLD NEW -f FILE` renames a key and rewrites whole-word references across the project; the editor offers the same cross-file rewrite on Encrypt & save.
  3. Feature`sopsdeck references -f FILE` lists each key with its reference count and files; `sopsdeck unused -f FILE` lists keys with zero references; the inspector shows an "unused" badge.
  4. FeatureNative Go runners for macOS, Windows, and Linux attach to GitHub Releases; the npm launcher downloads the matching runner.macOSWindowsLinux
  5. FeatureLanding install points at the npm package; the hero plays the catalog walkthrough.
  6. FeaturePublic site deploys with Wrangler from `site/`.
  7. FeatureDemo seed opens several Projects with nested Managed Files.
  8. FeatureNotes show type tags, group by Added/Fixed/Changed, and platform when a bullet names macOS, Windows, or Linux.macOSWindowsLinux
  9. FeatureNested Project folders collapse; recents reopen a folder from this machine; long lists use Show more.
  10. FeatureInspector sections collapse; reveal/hide values sits on the Value heading. Add secret is gone (composer remains).
  11. FeatureFailed CLI commands append to `$SOPSDECK_STATE_DIR/errors.json`; repeats increment a count. Messages never include private keys or ciphertext.
  12. Feature`./scripts/dev` builds a fresh CLI and launches the browser app against it.
  13. Feature`identity create` / `import` store the Age private key in the OS keychain; `SOPS_AGE_KEY_CMD='sopsdeck identity key'` decrypts. Existing `SOPS_AGE_KEY_FILE` still works.
  14. FeatureEditor paste sniffs dotenv, JSON, or YAML and previews key names until Apply paste.
  15. FeatureLocal MCP (`sopsdeck mcp`) returns metadata by default; `get_value` needs approval; `run` returns exit status only.
  16. Feature`set` reads dotenv, JSON, or YAML from stdin as a paste preview; `--yes` writes. Lone values need a KEY.
  17. Feature`scan` blocks staged cloud keys, private key PEMs, and common tokens; SOPS ciphertext is ignored; `--install` writes an opt-in pre-commit hook.
  18. FeatureInspector Publish shows repo, environment, prefix, and opt-in prune from `.sopsdeck.toml`.
  19. FeaturePublish uses `GH_TOKEN`, `GITHUB_TOKEN`, or `gh auth token` as the GitHub Authorization bearer.
  20. FeaturePublish encrypts each value with GitHub's Libsodium public key before sending it.
  21. FeaturePublish reads `.sopsdeck.toml` for repo, environment, prefix, keys, and last-published names; prune deletes only names Sopsdeck previously published.
  22. FeatureMarkdown in `docs/`, README, and CHANGELOG is linted; `./scripts/scan` runs govulncheck and bun audit. CI runs `./scripts/check`; opt-in hooks require a CHANGELOG bullet on user-facing commits.
  23. FeatureDocs, notes, and living pages share one public site under `site/` (landing, changelog, `site/docs/`).
  24. FeatureProduct clips hold for seconds with typed motion; `./scripts/demo --check` fails sub-second videos. CLI casts cover get, set, commit, and Sync.
  25. Feature`sopsdeck set -f FILE` with no KEY creates an empty encrypted Managed File.
  26. FeatureEditor key rows reveal, copy, rename, and delete from icons; a composer adds `KEY` or `KEY=value`.
  27. FeatureThe sidebar can add a Managed File; theme is an icon; panes scroll inside the window.
  28. FeatureInspector can Grant Access and dry-run or Publish to a Sync Target.
  29. Feature`recipient remove` drops Access, rotates the data key, and warns that Git history still decrypts.
  30. Feature`recipient request` opens a metadata-only access PR; `recipient grant` re-encrypts selected or all Managed Files and opens the Access PR.
  31. FeatureReview shows a plaintext semantic diff of uncommitted Managed File keys.
  32. FeatureSecret History lists commits on a Managed File; `get --at` decrypts a revision.
  33. FeatureRestore copies a revision’s values into the worktree and leaves them uncommitted.
  34. FeatureReview of a decryptable merge conflict shows base / ours / theirs for each key.
  35. FeatureInspector Review, History, and Restore call those CLI commands.
  36. FeatureProduct stills, clips, and a studio walkthrough are generated by `./scripts/demo`.
  37. Feature`sopsdeck --version` matches the npm launcher; What’s new is bundled from this file.
  38. Bug fixPlain dotenv files are no longer discovered as Managed Files (they failed to decrypt with parse errors); only SOPS-encrypted dotenv files are, matching the Project Manifest spec.
  39. Bug fixThe browser app logs failed CLI commands to `~/.config/sopsdeck/errors.json` and uses the keychain Age identity for decryption, so it works without a shell env.
  40. Bug fix`get` on a file without Access or on a non-SOPS file now says what to do instead of leaking a raw SOPS parse error.
  41. Bug fixAdding a Project path no longer depends on a native folder dialog.
  42. Bug fixOpening a large Project no longer blocks the browser: Managed File listing and decryption run in the Go runner, and the walker skips generated/build dirs (`.next`, `build`, `coverage`, `__pycache__`, …).
  43. Bug fixSync, get, and Publish print short recovery copy instead of raw Git or SOPS text.
  44. Bug fixThe browser shows Sync, commit, and save failures next to those controls, not as a toast.
  45. Bug fix`get` of encrypted `eas.json` warns that EAS CLI will not read SOPS ciphertext.
  46. Bug fixBrowser breadcrumb and inspector show `~/project/file` paths, not temp or `..` paths.
